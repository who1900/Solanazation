# Geist font provenance

Solanazation packages these unmodified font binaries from the official
[`vercel/geist-font`](https://github.com/vercel/geist-font) repository at tag
[`v1.7.2`](https://github.com/vercel/geist-font/releases/tag/v1.7.2), published
2026-06-01.

License: SIL Open Font License 1.1. The complete upstream license is included as
`LICENSE-Geist.txt` in this directory.

The files were fetched from the pinned tag through the GitHub contents API. No
third-party mirror or font conversion was used.
