Solanazation

Solanazation is a portrait mobile 4X strategy prototype for Android/Seeker, built in Godot 4.4.1 with GDScript. Its current offline game loop combines map exploration, persistent fog memory, city founding and production, an educational Solana technology tree, multiple AI rivals, turn guidance, and local saves.

What works today

The offline strategy core is implemented and can be run from scenes/Main.tscn. City-depth work remains in progress and is not fully accepted into the stable baseline.

Solana integration

Mobile Wallet Adapter integration is planned but its Kotlin plugin has not yet been applied, compiled, or device-tested. The documented staking design uses an existing LST with separate nonredeemable cosmetic gameplay credits. No live staking, credits backend, custody, or mainnet flow exists today.
